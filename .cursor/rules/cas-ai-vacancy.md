# CAS.AI — Middle Fullstack Developer

**Стек:** Laravel + Vue 3 + Node.js (NestJS), MySQL/PostgreSQL, ClickHouse, очереди, REST API, Docker, AI-инструменты.

## Продукт

Мобильная рекламная медиация для игровых студий. Финансовые дашборды, интеграции с платёжными системами (billing, payouts, reconciliation), большие объёмы данных.

## Основные задачи

- Финансовые дашборды на Laravel + Vue 3 (графики, таблицы, фильтры, экспорты)
- API-интеграции с платёжными системами и внешними сервисами
- Большие объёмы данных и ClickHouse
- Рефакторинг legacy, вынос логики в сервисы, тесты
- Code review и архитектурные обсуждения
- Unit и feature тесты
- AI-инструменты (Claude Code, Cursor) с полным пониманием сгенерированного кода
- Микросервисы на Node.js (NestJS), асинхронное взаимодействие (очереди, события)

## Ожидания

- 2+ года коммерческого Fullstack PHP/Laravel + Vue.js
- Реляционные БД (MySQL/PostgreSQL), сложная бизнес-логика
- REST API, Node.js (NestJS — плюс)
- Очереди сообщений и асинхронная обработка
- Архитектурные паттерны, умение аргументировать технические решения

## Ключевые навыки

- PHP 8+ / Laravel: Eloquent, Queues, Events, Middleware, Service Providers, Feature Tests
- Vue 3: Composition API, Pinia, реактивность, компонентная архитектура
- SQL: JOIN, индексы, оптимизация, EXPLAIN
- REST API: проектирование, версионирование, авторизация (JWT/Sanctum)
- Git: feature branches, pull requests, code review
- Читать и рефакторить чужой код

## Будет плюсом

- ClickHouse или другие колоночные БД
- Платёжные системы (Stripe, Adyen, PSP)
- Docker, CI/CD, TypeScript, AWS (ECS, RDS, CloudFront, ElastiCache)
- AI-инструменты в процессе разработки

## Фокус подготовки к собеседованию

- Laravel: тонкие контроллеры, сервисы, Form Requests, API Resources, тесты
- Vue 3: Composition API, Pinia, таблицы/фильтры
- SQL, REST, Sanctum — уверенно на словах
- Node/NestJS, ClickHouse, платежи — концептуально на первом этапе
- Live coding: простые решения, объяснять вслух, AI как помощник, не автопилот
